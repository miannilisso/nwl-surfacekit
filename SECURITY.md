# Security Policy

## Reporting a vulnerability

Please report suspected vulnerabilities through a private GitHub security
advisory for this repository. Include affected versions, reproduction steps,
impact, and any mitigations already tested. Do not open a public issue for an
unfixed security vulnerability.

Naneware Labs will acknowledge reports within five business days, provide a
status update within ten business days, and coordinate disclosure after a fix
is available. Supported versions are listed in RELEASE.md.
