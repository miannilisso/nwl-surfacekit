# Support Policy

Use GitHub Issues for reproducible bugs, accessibility regressions, and feature
requests. Include the SurfaceKit version, React version, browser/runtime, and a
minimal reproduction where possible.

The repository is currently private and no stable external release exists.
Issue access may therefore be limited to repository collaborators. For
security-sensitive reports, follow [SECURITY.md](SECURITY.md) rather than
filing a public issue. After the first accepted release, community support
targets the latest stable line; maintenance and upgrade decisions are described
in [RELEASE.md](RELEASE.md).
